# Ads Lab

Исследовательский Python-проект для моделирования адсорбции, сравнения решёточных геометрий и проверки термодинамических расчётов.

## Модели и методы

| Модель | Методы | Результаты |
| --- | --- | --- |
| Однокомпонентный газ на квадратной, треугольной и сотовой решётках | Трансфер-матрица, Монте-Карло (Метрополис) | Заполнение, энергия и отклик заполнения |
| Газ с исключением ближайших соседей на кагоме | Точный перебор, Монте-Карло | Заполнение и коэффициенты статистической суммы |
| Непрерывные двумерные жёсткие диски | Монте-Карло с локальными ходами | Координаты, плотность, доля занятой площади |
| Квадратный периодический решёточный газ | HOTRG | Статистическая сумма и большой потенциал на узел |

## Быстрый старт

Требуется Python 3.11 или новее.

```bash
git clone https://github.com/snapdeveloper667/Ads-lab.git
cd Ads-lab
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python run.py --help
```

В Windows PowerShell активируйте окружение командой `.venv\Scripts\Activate.ps1`.

```bash
python run.py transfer --geometry triangular --width 4 --height 5
python run.py metropolis --geometry triangular --width 4 --height 5 --sweeps 10000 --burn 2000 --seed 42
python run.py disks --count 36 --fraction 0.4 --seed 42
python run.py hotrg --levels 3 --bond-dim 8
python kagome.py exact
python kagome.py metropolis --sweeps 10000 --seed 42
```

Результаты печатаются в JSON. Сохраняйте параметры запуска и seed рядом с результатами эксперимента.

## Контрольный расчёт

Кагоме, 2×2 периодические ячейки, 12 узлов, исключение ближайших соседей, μ = 0. Точный перебор даёт коэффициенты статистической суммы `[1, 12, 42, 44, 9]` и заполнение `11/54 ≈ 0.203704`.

## Соглашения и ограничения

- Для решёточного газа используется энергия `H = −J B`, где `B` — число занятых пар ближайших соседей, и единицы `k_B = 1`. Заполнение нормируется на число узлов.
- Обычная трансфер-матрица и решёточный Метрополис используют открытые границы. Кагоме, жёсткие диски и HOTRG используют периодические границы. Для сравнения конечных систем границы должны совпадать.
- HOTRG использует усечение. Проверяйте сходимость при изменении размерности связи. Результаты Монте-Карло пока выводятся без оценок статистической погрешности.
- Бинарный газ, ступенчатые дефекты, генерация снимков методом трансфер-матрицы и event-chain для дисков остаются направлениями развития.

## Структура

- `run.py` — запуск расчётов.
- `models.py` — геометрии и жёсткие диски.
- `methods.py` — трансфер-матрица и решёточный Метрополис.
- `tensor.py` — HOTRG.
- `kagome.py` — расчёты для кагоме.
- `requirements.txt` — зависимости Python.

## Научный контекст

- [SuSMoST](https://susmost.com/) и [TeNeT](https://github.com/IakOBiaN/tenet) — внешние проекты для сравнения моделей и методов.
- [Akimenko et al., 2019](https://doi.org/10.1103/PhysRevE.100.022108) — решёточные hard-core модели на треугольной решётке.
- [Kano и Naya, 1953](https://doi.org/10.1143/PTP.10.158) — точная модель Изинга на кагоме.
